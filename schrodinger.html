基本方程式 (式①〜④)

式番号 数式 解説
式① $$psi(mathbf{r}, t) = psi_0 e^{i(mathbf{k} cdot mathbf{r} - omega t)}$$ 平面波の仮定。位相は空間に対して k、時間に対して ω で進む。確率密度は |ψ|²
式② $mathbf{k} = k_x hat{i} + k_y hat{j} + k_z hat{k}$
$k = sqrt{k_x^2 + k_y^2 + k_z^2}$		 波数ベクトルの成分表示。大きさ k は三平方の定理
式③ $mathbf{r} = xhat{i} + yhat{j} + zhat{k}$
$mathbf{k} cdot mathbf{r} = k_x x + k_y y + k_z z$		 位置ベクトルの成分表示と内積の展開
式④ $$psi(mathbf{r}, t) = psi_0 e^{i(k_x x + k_y y + k_z z - omega t)}$$ ①〜③を成分に落とした形。以後の微分はこの形で計算
