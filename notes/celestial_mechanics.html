1
第1問：2体問題の設定

「重力のみで相互作用する2つの質点からなる系がある。この系の運動について述べよ」

質点1, 2の位置を $\vec{R}_1$, $\vec{R}_2$、相対位置ベクトルを $\vec{r} = \vec{R}_2 - \vec{R}_1$ とする。

万有引力

$$\vec{F}_{12} = G \frac{M_1 M_2}{|\vec{r}|^2} \frac{\vec{r}}{|\vec{r}|} \quad \cdots (1)$$
$$\vec{F}_{21} = -G \frac{M_1 M_2}{|\vec{r}|^2} \frac{\vec{r}}{|\vec{r}|} \quad \cdots (2)$$

作用・反作用の法則より $\vec{F}_{12} + \vec{F}_{21} = 0$

運動方程式

$$\vec{F}_{12} = M_1 \ddot{\vec{R}}_1, \quad \vec{F}_{21} = M_2 \ddot{\vec{R}}_2$$

①+②を計算すると：

$$M_1 \ddot{\vec{R}}_1 + M_2 \ddot{\vec{R}}_2 = 0 \quad \cdots (3)$$

運動量保存

③の両辺を時間積分すると：

$$M_1 \dot{\vec{R}}_1 + M_2 \dot{\vec{R}}_2 = \vec{P} \quad \text{（Pは積分定数）} \quad \cdots (4)$$

$\dot{\vec{R}}_1$, $\dot{\vec{R}}_2$ は質点の速度である。これは運動量保存の法則を表す。

更に時間で積分して：

$$M_1 \vec{R}_1 + M_2 \vec{R}_2 = \vec{P}t + \vec{Q} \quad \text{（Qは積分定数）} \quad \cdots (5)$$

重心の運動

両辺を $M_1 + M_2$ で割る：

$$\vec{R}_G = \frac{M_1 \vec{R}_1 + M_2 \vec{R}_2}{M_1 + M_2} = \frac{\vec{P}}{M_1 + M_2}t + \frac{\vec{Q}}{M_1 + M_2}$$

（$\frac{\vec{P}}{M_1+M_2}$：初速度、$\frac{\vec{Q}}{M_1+M_2}$：初期座標）

これを時間で2階微分すると：

$$\ddot{\vec{R}}_G = 0 \quad \cdots (6)$$
結論：重心は等速直線運動をしている。

2
相対運動と換算質量

相対位置ベクトルを $\vec{r} = \vec{R}_2 - \vec{R}_1$ と定義する。

両辺を時間で2階微分すると：

$$\ddot{\vec{r}} = \ddot{\vec{R}}_2 - \ddot{\vec{R}}_1$$

運動方程式より $M_2\ddot{\vec{R}}_2 = \vec{F}_{21}$, $M_1\ddot{\vec{R}}_1 = \vec{F}_{12}$

$$\ddot{\vec{r}} = \frac{\vec{F}_{21}}{M_2} - \frac{\vec{F}_{12}}{M_1}$$

②式 $\vec{F}_{21} = -\vec{F}_{12}$ を用いると：

$$\ddot{\vec{r}} = -\vec{F}_{12}\left(\frac{1}{M_1} + \frac{1}{M_2}\right)$$

換算質量（縮約質量）

$$\frac{1}{\mu} = \frac{1}{M_1} + \frac{1}{M_2} \quad \cdots (7)$$

すなわち：

$$\mu = \frac{M_1 M_2}{M_1 + M_2} \quad \cdots (8)$$

このとき、相対運動の運動方程式は：

$$\mu \ddot{\vec{r}} = \vec{F}_{21} \quad \cdots (9)$$

①式を代入すると：

$$\mu \ddot{\vec{r}} = -G\frac{M_1 M_2}{r^2}\frac{\vec{r}}{r} \quad \cdots (10)$$

よって：

$$\ddot{\vec{r}} = -G\frac{M_1 + M_2}{r^2}\frac{\vec{r}}{r} \quad \cdots (11)$$

重心運動と相対運動の分離

以上より、2体問題は次の2つに分離できる：

  • 重心の等速直線運動
  • 換算質量 $\mu$ をもつ1粒子の中心力運動

これを重心運動と相対運動の分離という。

3
極座標での運動方程式

位置ベクトルと速度の極座標表示：

$$\vec{r} = r\hat{r} \quad \cdots (1')$$
$$\vec{v} = \dot{r}\hat{r} + r\dot{\theta}\hat{\theta} \quad \cdots (2')$$

単位ベクトルの時間微分：

$$\dot{\hat{r}} = \dot{\theta}\hat{\theta} \quad \cdots (3')$$
$$\dot{\hat{\theta}} = -\dot{\theta}\hat{r} \quad \cdots (4')$$

加速度は：

$$\vec{a} = (\ddot{r} - r\dot{\theta}^2)\hat{r} + (2\dot{r}\dot{\theta} + r\ddot{\theta})\hat{\theta} \quad \cdots (6')$$

(17), (18) を (12) に代入すると：

$$\ddot{r}\cos\theta - 2\dot{r}\dot{\theta}\sin\theta - r\dot{\theta}^2\cos\theta - r\ddot{\theta}\sin\theta = -\frac{\mu}{r^2}\cos\theta \quad \cdots (19)$$
$$\ddot{r}\sin\theta + 2\dot{r}\dot{\theta}\cos\theta - r\dot{\theta}^2\sin\theta + r\ddot{\theta}\cos\theta = -\frac{\mu}{r^2}\sin\theta \quad \cdots (20)$$

行列形式への変換

2つの式を整理すると：

$$\begin{cases} (\ddot{r} - r\dot{\theta}^2 + \frac{\mu}{r^2})\cos\theta - (2\dot{r}\dot{\theta} + r\ddot{\theta})\sin\theta = 0 \\ (\ddot{r} - r\dot{\theta}^2 + \frac{\mu}{r^2})\sin\theta + (2\dot{r}\dot{\theta} + r\ddot{\theta})\cos\theta = 0 \end{cases}$$

これを行列の形に直す：

$$\begin{pmatrix} \ddot{r} - r\dot{\theta}^2 + \frac{\mu}{r^2} & -(2\dot{r}\dot{\theta} + r\ddot{\theta}) \\ 2\dot{r}\dot{\theta} + r\ddot{\theta} & \ddot{r} - r\dot{\theta}^2 + \frac{\mu}{r^2} \end{pmatrix} \begin{pmatrix} \cos\theta \\ \sin\theta \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix} \quad \cdots (21)$$

$(\cos\theta, \sin\theta) \neq (0, 0)$ より $\det A = 0$

$$\det A = \left(\ddot{r} - r\dot{\theta}^2 + \frac{\mu}{r^2}\right)^2 + (2\dot{r}\dot{\theta} + r\ddot{\theta})^2 = 0 \quad \cdots (22)$$

よって：

$$\ddot{r} - r\dot{\theta}^2 + \frac{\mu}{r^2} = 0 \quad \cdots (23)$$
$$2\dot{r}\dot{\theta} + r\ddot{\theta} = 0 \quad \cdots (24)$$

角運動量保存

(24)式は次のように書ける：

$$\frac{d}{dt}(r^2\dot{\theta}) = 0 \quad \cdots (25)$$

よって：

$$r^2\dot{\theta} = h \quad \text{（hは定数）} \quad \cdots (26)$$

$h$ は単位質量あたりの角運動量である。

4
軌道方程式の導出

(23), (26) を用いて、(23)式を $r$ のみの式に書き換える：

$$\ddot{r} - \frac{h^2}{r^3} + \frac{\mu}{r^2} = 0 \quad \cdots (27)$$

変数変換

変数変換 $u = \frac{1}{r}$ を行う：

$$u = \frac{1}{r} \quad \cdots (28)$$

(26)式より：

$$\dot{\theta} = hu^2 \quad \cdots (29)$$

時間微分を角度微分に変換する：

$$\frac{dr}{dt} = \frac{dr}{d\theta}\frac{d\theta}{dt}$$
$$\dot{r} = \frac{dr}{d\theta} \cdot hu^2 \quad \cdots (30)$$

$r = \frac{1}{u}$ より：

$$\dot{r} = -\frac{h}{u^2}\frac{du}{d\theta} \quad \cdots (31)$$

さらに時間微分すると：

$$\ddot{r} = -h\frac{d}{dt}\left(\frac{1}{u^2}\frac{du}{d\theta}\right)$$
$$\ddot{r} = -h^2u^2\frac{d}{d\theta}\left(\frac{1}{u^2}\frac{du}{d\theta}\right) \quad \cdots (32)$$

計算すると：

$$\ddot{r} = h^2\left(2u\left(\frac{du}{d\theta}\right)^2 - u^2\frac{d^2u}{d\theta^2}\right) \quad \cdots (33)$$

微分方程式への代入

(27)式に代入する：

$$h^2\left(2u\left(\frac{du}{d\theta}\right)^2 - u^2\frac{d^2u}{d\theta^2}\right) - h^2u^3 + \mu u^2 = 0$$

両辺を $u^2$ で割る：

$$-h^2\frac{d^2u}{d\theta^2} - h^2u + \mu = 0$$
$$\frac{d^2u}{d\theta^2} + u = \frac{\mu}{h^2} \quad \cdots (34)$$

軌道方程式の解

これは定数項をもつ2階線形微分方程式である。特解を $u = \frac{\mu}{h^2}$ とすると、同次方程式は：

$$\frac{d^2u}{d\theta^2} + u = 0$$

その一般解は：

$$u = A\cos\theta + B\sin\theta$$

よって (34)式の一般解は：

$$u = A\cos\theta + B\sin\theta + \frac{\mu}{h^2} \quad \cdots (35)$$

定数 $A$, $B$ をまとめて：

$$u = \frac{\mu}{h^2}(1 + e\cos\theta) \quad \cdots (36)$$

ここで $e$ は定数であり、離心率と呼ばれる。$u = \frac{1}{r}$ より：

$$r = \frac{h^2/\mu}{1 + e\cos\theta} = \frac{p}{1 + e\cos\theta} \quad \cdots (37)$$

これが逆二乗力下における運動方程式の解である。

5
デカルト座標への変換

(37)式を $x$, $y$ 座標で表す。図より：

$$x = r\cos\theta, \quad y = r\sin\theta$$

よって：

$$r = \sqrt{x^2 + y^2}, \quad \cos\theta = \frac{x}{\sqrt{x^2 + y^2}}$$

これを (37) 式に代入する：

$$\sqrt{x^2 + y^2} = \frac{p}{1 + e\frac{x}{\sqrt{x^2 + y^2}}}$$

両辺に $1 + e\frac{x}{\sqrt{x^2+y^2}}$ を掛ける：

$$\sqrt{x^2 + y^2} + ex = p$$

移項して：

$$\sqrt{x^2 + y^2} = p - ex$$

両辺を2乗する：

$$x^2 + y^2 = p^2 - 2pex + e^2x^2$$

整理すると：

$$(1 - e^2)x^2 + y^2 + 2pex - p^2 = 0 \quad \cdots (38)$$

楕円の方程式

平方完成を行う：

$$(1 - e^2)\left(x + \frac{pe}{1-e^2}\right)^2 + y^2 = \frac{p^2}{1-e^2}$$

両辺を $\frac{p^2}{1-e^2}$ で割る：

$$\frac{\left(x + \frac{pe}{1-e^2}\right)^2}{\left(\frac{p}{1-e^2}\right)^2} + \frac{y^2}{\frac{p^2}{1-e^2}} = 1 \quad \cdots (39)$$

これは楕円の方程式である。従って、逆二乗力のもとでの運動は円錐曲線となる。

6
軌道の分類とエネルギー

エネルギーの計算：

$$E = \frac{M_r k^2}{2p^2}(e^2 - 1) \quad \cdots (43)$$

式(43)よりエネルギーが定数であることが分かる。離心率 $e$ により軌道の形は次のように分類される：

[I] $e = 1$ の場合：放物線軌道

(37)式より $e = 1$ を代入すると：

$$x = \frac{p}{2} - \frac{y^2}{2p} \quad \cdots (44)$$

焦点は原点にあり、天体 $M_2$ は $M_1$ を焦点として放物運動をする。このときのエネルギーは $E = 0$。この軌道上の物体は無限遠で静止する。

[II] $0 < e < 1$ の場合：楕円軌道

式(43)から全エネルギー $E$ は負である。物体が無限遠に行かず、ある領域に閉じ込められた運動を描く。

楕円の長半径 $a$ および短半径 $b$ は：

$$a = \frac{p}{1-e^2} = \frac{k^2}{\mu(1-e^2)}$$
$$b = \sqrt{\frac{p^2}{1-e^2}} = \frac{k^2}{\mu\sqrt{1-e^2}} \quad \cdots (45)$$

また次式が成り立つ：

$$\frac{b}{a} = \sqrt{1-e^2} \quad \cdots (46)$$

[III] $e > 1$ の場合：双曲線軌道

式(43)より全エネルギーは正。無限遠でポテンシャルが0であるから、この物体は無限遠に飛び去る。

$$\frac{\left(x + \frac{pe}{1-e^2}\right)^2}{\left(\frac{p}{1-e^2}\right)^2} - \frac{y^2}{\left(\sqrt{\frac{p^2}{e^2-1}}\right)^2} = 1 \quad \cdots (47)$$

これは双曲線を表す。

  • $0 \leq e < 1$：楕円軌道（束縛状態、$E < 0$）
  • $e = 1$：放物線軌道（$E = 0$、無限遠で静止）
  • $e > 1$：双曲線軌道（$E > 0$、無限遠へ飛び去る）

7
ケプラー第2法則

太陽の質量が十分大きく、太陽はほぼ静止しているとみなせる。$M_1 \gg M_2$ のとき $M_r \simeq M_2$。

重心の位置は：

$$\vec{R}_G = \frac{M_1\vec{R}_1 + M_2\vec{R}_2}{M_1 + M_2} \simeq \vec{R}_1$$

よって太陽はほとんど動かない。角運動量保存より：

$$\vec{r} \times \vec{v} = \text{const}$$

面積速度

微小時間 $dt$ において天体が掃く面積 $dS$ は：

$$dS = \frac{1}{2}|\vec{r} \times d\vec{r}|$$

両辺を時間で割ると：

$$\frac{dS}{dt} = \frac{1}{2}|\vec{r} \times \vec{v}| \quad \cdots (49)$$

右辺は定数であるから、面積速度は一定である。従って式(49)を時間積分すると：

$$S = \text{const} \times t \quad \cdots (50)$$

よって (49) は：

$$|S| = \frac{1}{2}|\vec{r} \times \dot{\vec{r}}| = \frac{1}{2}r^2\dot{\theta} \quad \cdots (53)$$

また (26) より $h = r^2\dot{\theta}$ だから：

$$S = \frac{1}{2}h \quad \cdots (54)$$

よって面積速度は一定であり、角運動量の保存と等価である。

ケプラー第2法則：惑星は等時間に等面積を掃く。

8
ケプラー第3法則

楕円の面積は $\pi ab$ であるから：

$$\frac{1}{2}Th = \pi ab \quad \cdots (55)$$

楕円の性質より $b = a\sqrt{1-e^2}$、$p = a(1-e^2)$ を用いると：

$$T^2 = \frac{4\pi^2}{\mu}a^3$$
ケプラー第3法則：公転周期の2乗は軌道長半径の3乗に比例する。

9
第2問：3体問題

「重力のみで相互作用する3つ以上の質点からなる系において、質量分布をもつ系の運動について述べよ」

3つ以上の質点からなる系を解析的に解くことは一般に困難である。極めて特殊な場合として、$M_3$ が十分小さく、$M_1$, $M_2$ の運動に影響を与えないと仮定する。

円運動する2天体

$M_1$, $M_2$ は互いに円運動を行い、一定の角速度 $\omega$ で回転する。この角速度は周期 $T$ に対して：

$$\omega = \frac{2\pi}{T} \quad \cdots (57)$$

(56), (57) を連立すると：

$$\omega^2 = \frac{4\pi^2}{T^2} \Rightarrow T^2 = \frac{4\pi^2}{\omega^2}$$

これを (56) に代入して：

$$\omega^2 = \frac{\mu}{a^3} = \frac{G(M_1 + M_2)}{a^3} \quad \cdots (58)$$

重心座標系

$M_1$, $M_2$ の重心を原点とする座標系をとる。原点の条件より：

$$0 = \frac{M_1 x_1 + M_2 x_2}{M_1 + M_2} \quad \cdots (59)$$

軌道半径 $a$ は：

$$a = |x_2 - x_1| = \frac{h^2}{G(M_1 + M_2)} \quad \cdots (60)$$

(59) より：

$$x_1 = -\frac{M_2}{M_1 + M_2}a, \quad x_2 = \frac{M_1}{M_1 + M_2}a \quad \cdots (61)$$

10
回転座標系での運動方程式

回転座標系では慣性力が働くため、運動方程式は非慣性系で書かれる。座標変換は：

$$\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} \cos\omega t & \sin\omega t \\ -\sin\omega t & \cos\omega t \end{pmatrix} \begin{pmatrix} x' \\ y' \end{pmatrix} \quad \cdots (62)$$

回転行列を $A$ とすると：

$$A = \begin{pmatrix} \cos\omega t & \sin\omega t \\ -\sin\omega t & \cos\omega t \end{pmatrix} \quad \cdots (63)$$
$$\vec{r} = A\vec{r}' \quad \cdots (64)$$

(64) を2階微分して：

$$\ddot{\vec{r}} = A\ddot{\vec{r}}' + 2\dot{A}\dot{\vec{r}}' + \ddot{A}\vec{r}' \quad \cdots (65)$$

$M_3$ の運動方程式：

$$\ddot{\vec{r}}_3 = -G\left(\frac{(\vec{r}_3 - \vec{r}_1)}{|\vec{r}_3 - \vec{r}_1|^3}M_1 + \frac{(\vec{r}_3 - \vec{r}_2)}{|\vec{r}_3 - \vec{r}_2|^3}M_2\right) \quad \cdots (66)$$

逆行列 $A^{-1}$ を用いると：

$$\ddot{\vec{r}}'_3 + 2\vec{\omega} \times \dot{\vec{r}}'_3 + \vec{\omega} \times (\vec{\omega} \times \vec{r}'_3) = -G\left(\frac{(\vec{r}'_3 - \vec{r}'_1)}{|\vec{r}'_3 - \vec{r}'_1|^3}M_1 + \frac{(\vec{r}'_3 - \vec{r}'_2)}{|\vec{r}'_3 - \vec{r}'_2|^3}M_2\right) \quad \cdots (68)$$

$M_3$ の初速度が相対的に小さいと仮定し、$\dot{\vec{r}}'_3 = 0$ の場合を考える。釣り合いの条件：

$$-\omega^2\vec{r}' = -G\left(\frac{(\vec{r}' - \vec{r}'_1)}{|\vec{r}' - \vec{r}'_1|^3}M_1 + \frac{(\vec{r}' - \vec{r}'_2)}{|\vec{r}' - \vec{r}'_2|^3}M_2\right) \quad \cdots (69)$$

11
ラグランジュ点

また (61) より：

$$\vec{r}'_1 = \begin{pmatrix} -\frac{aM_2}{M_1 + M_2} \\ 0 \end{pmatrix}, \quad \vec{r}'_2 = \begin{pmatrix} \frac{aM_1}{M_1 + M_2} \\ 0 \end{pmatrix} \quad \cdots (70)$$

一直線上の解（L1, L2, L3）

(69) を $x$ 成分について書くと：

$$\omega^2 x'_3 = GM_1\frac{x'_3 - x'_1}{|x'_3 - x'_1|^3} + GM_2\frac{x'_3 - x'_2}{|x'_3 - x'_2|^3} \quad \cdots (71)$$

$y$ 成分については：

$$\omega^2 y' = G\left(\frac{M_1}{r_{13}^3} + \frac{M_2}{r_{23}^3}\right)y' \quad \cdots (72)$$

(72) より $y' = 0$ または $\omega^2 = G\left(\frac{M_1}{r_{13}^3} + \frac{M_2}{r_{23}^3}\right)$ である。

$y'_3 = 0$ のとき、3天体は一直線上に並ぶ。このとき：

$$x'_3 = x'_2 \pm a \quad \cdots (73)$$
$$r_{13} = |1 + \lambda|a, \quad r_{23} = |\lambda|a \quad \cdots (74)$$

これらを (71), (72) に代入すると：

$$\frac{\mu}{a^3} = \frac{GM_1}{a^3|1 + \lambda|^3} + \frac{GM_2}{a^3|\lambda|^3} \quad \cdots (75)$$

一般には解析解を持たず、数値的に解かれる。グラフより解は3つ存在し、これらがラグランジュ点 $L_1$, $L_2$, $L_3$ に対応する。

正三角形の解（L4, L5）

対称性より $r_{13} = r_{23}$ が成り立つ場合があり、さらに3天体が正三角形の頂点に位置する解が存在する。これがラグランジュ点 $L_4$, $L_5$ である。この場合、$M_3$ に働く重力は $M_1$, $M_2$ からの力が合成され、遠心力と釣り合う。

12
ラグランジュ点の安定性

5つのラグランジュ点

  • $L_1$：$M_1$ と $M_2$ の間（不安定）
  • $L_2$：$M_2$ の外側（不安定）
  • $L_3$：$M_1$ の外側（不安定）
  • $L_4$：$M_1 M_2$ を底辺とする正三角形の頂点（安定）
  • $L_5$：$M_1 M_2$ を底辺とする正三角形の頂点（安定）
応用例：$L_4$, $L_5$ にはトロヤ群小惑星が存在する。JWST（ジェイムズ・ウェッブ宇宙望遠鏡）は太陽-地球系の $L_2$ に配置されている。
